# Acre

Art and a playable-looking preview for a top-down island farming game, in a flat, faceted, low-poly style.

- **Creatures**: hand-tuned five-colour SVG creatures (side views in the folders by theme, top-down companions in `topdown/`).
- **Crops**: every crop in eight stages, from seed to harvest to dried out (`crops/`, generators in `tools/crops/`).
- **Tiles**: seamless ground, water, sea, sand, rock, paths, fences, bridges, trees and small details (`tiles/`, generated by `tools/tiles/tiles.pl`).
- **Island preview**: `topdown/tiles.html` builds a random 100 x 100 island (mountains, forests, beaches, lakes, rivers, fields, enclosures, paths, creatures and weather) with a settings panel for every chance and count.

## Run it

The pages load files with `fetch`, so they need a local web server:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Then open <http://localhost:5181/> (gallery) or <http://localhost:5181/topdown/index.html> (game art sheets).

## Rebuild the tiles

```bash
perl tools/tiles/tiles.pl
```
